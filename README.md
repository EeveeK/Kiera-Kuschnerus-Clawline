# Kiera Kuschnerus Clawline

I decided to prototype the clawline from Hollow Knight Silksong. It basically stops Hornet's movement then goes in a horizontal direction until it hits something and then deals damage or just stops.

I used an interface to calculate damage. I also did an interface to decide what things were hittable which stops Hornet's clawline from going through it. 

I did have to shrink my idea. Figuring out which direction was being faced to shoot the clawline in that direction ended up being harder than I thought it would be. So I decided to just make it go left for now.
